# Página de Viagem

Bem-vindo ao repositório do projeto **Página de Viagem**! Este é um site simples e responsivo que apresenta informações sobre destinos de viagem, dicas e inspirações para viajantes.

## 🌐 Link do Projeto

Acesse o site ao vivo aqui: [Página de Viagem](https://eugiovaniii.github.io/pagina-de-viagem/)

## 📋 Funcionalidades

- Design responsivo para diferentes dispositivos.
- Informações sobre destinos populares.
- Seções organizadas para facilitar a navegação.
- Estilo visual agradável com CSS.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura do site.
- **CSS3**: Estilização e layout.
